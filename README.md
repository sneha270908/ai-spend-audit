# AI Spend Audit

A free web app that audits your AI tool spending and shows you exactly where you're overspending. Built for startup founders and engineering managers who pay for Cursor, Claude, ChatGPT, GitHub Copilot, and other AI tools without knowing if they're on the right plan.

**Live URL:** https://ai-spend-audit-quru.vercel.app
